구성
- 메인페이지: index.html
- 상세페이지: 34개 (전체 팩션 완료)
- 공통 상세페이지 스타일: assets/detail-common.css
- 공통 상세페이지 스크립트: assets/detail-common.js
- 메타데이터: manifest.json
- 최종 검증 보고서: FINAL-AUDIT-REPORT.txt
- 체크섬: SHA256SUMS.txt
- 상세페이지 구성: 1~8 섹션 (에라타 섹션은 사용하지 않습니다)
- 구매 가이드: 34개 전 페이지 4항목 요약 카드 구조 (한 박스 게임 / 권장 박스 수 또는 권장 구성 / 구매 가격 / 자석질)
- Q2 디자인 개선: 히어로 위계, 섹션 헤더, 카드 깊이/호버, 펼침 상태, 구매 가이드 시각 디자인을 공통 CSS에서 개선
- 죽음의 천사 상세페이지: 임시 AOD 방패 아이콘과 배경 X/광원 효과를 제거하고, 제공된 주황 엠블럼의 투명 배경 버전을 적용
- 고정 바로가기 메뉴: 데스크톱은 화면 좌측 세로 고정, 태블릿/모바일은 헤더 아래 가로 고정(좌우 스크롤 가능); 현재 보고 있는 섹션의 링크가 금색으로 강조됨

사용 방법
1. ZIP 파일의 압축을 풉니다.
2. 최상위 폴더의 index.html을 웹브라우저로 엽니다.
3. 메인페이지의 34개 팩션 카드 모두 상세페이지로 연결됩니다.
4. 상세페이지의 Kill Team Core 로고 또는 “팩션 목록으로”를 누르면 메인페이지로 돌아옵니다.
